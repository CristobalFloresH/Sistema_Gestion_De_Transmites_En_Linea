# Proyecto_Final_INF3245


Requerimientos funcionales
1. El sistema enviara un correo automáticamente con la información al correo  del usuario
2. El sitio web permitira al usuario ingresar con su rut y clave unica
3. La pagina contara con un calendario donde el usuario podra ver los dias disponibles
4. Se permitirá enviar los documentos solicitados a través de la pagina
5. Se enviara un correo 1 día antes de la hora agendada para recordar al usaurio
6. El funcionario podra ver los documentos enviados de los usuarios 
7. Tanto los funcionario como los usuarios, podran ver en que parte del proceso va (Indicar procesos) 
8. El sistema reconocerá si al ingresar los datos eres usuario o funcionario
9. El funcionario podra ver una lista de las personas asignadas a X horario
10. El usuario sera notificado cuando la licencia de conducir este impresa y lista para retirar
11. El sistema permitira guardar las horas agendadas

Requerimientos no funcionales
1. Verificar identidad de persona con rut, numero de documento y clave unica
2. Respuesta en maximo 2 segundos
3. Se verificara la legitimidad de los documentos
4. El sistema podra agendar horas solo de 11:00 a 12:00 de lunes a viernes
5. El sistema debera poder aguantar una cantidad de 70.000 personas
